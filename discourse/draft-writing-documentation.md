### Diátaxis

I recently found this really nice resource which describes four types of documentation according to the user need. Many of the problems of poor documentation stem from blurring the boundaries they describe here.

https://diataxis.fr/

We haven't knowingly used Diátaxis in our documentation, but I would suggest we should  consider bringing some of these concepts into any updates to the documentation we maintain.
