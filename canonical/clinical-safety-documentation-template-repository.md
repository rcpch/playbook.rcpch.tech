When we created the [dGC clinical safety documentation](https://growth.rcpch.ac.uk/), we took the decision to do it
* fully public and in the open,
* with Markdown content source (as opposed to a Word doc),
* managing the Hazards as GitHub issues in the open,
* using a common documentation framework (Material for MkDocs) to make it into a good looking website.

After we completed that work I extracted out and published the 'generic' part of the clinical safety docs so that they would be useful for future projects, for us and for others. 

https://github.com/turva-uk/csmf-mkdocs-template

It makes it quite quick and easy to get up and running with clinical safety documentation for a new project, and then publish that repo on GitHub Pages.

Together with a few others I've started working on ways to make this easier to use for non-techy users. That stuff is being done as a mini startup project, watch this space. The underlying Markdown/Git stuff will of course always be open source.
